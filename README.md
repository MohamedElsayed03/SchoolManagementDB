# School Management Database

## Overview

This project is a SQL Server database designed to manage the core operations of a school management system.

The database handles:

- Departments
- Students
- Teachers
- Courses
- Student Enrollments

The project demonstrates database design and practical SQL Server concepts, including table relationships, joins, views, stored procedures, functions, transactions, error handling, and indexing.

## ERD

The Entity Relationship Diagram is included in the `ERD` folder.

The ERD represents the relationships between the main entities in the database.
